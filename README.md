# Binance Ledger Pro — PWA (GitHub Pages Ready) 🚀

نسخة **تطبيق الويب التقدمي (PWA)** الكاملة والخالية من الأخطاء، المجهزة للرفع المباشر على **GitHub Pages** والمتوافقة 100% مع الملف المحلي المخزن على ذاكرة الجهاز.

## 📦 محتويات الحزمة
- `index.html` — التطبيق الكامل (يدعم العمل كملف محلي على الذاكرة وكتطبيق PWA على GitHub Pages بنفس الكود والبيانات).
- `manifest.json` — ملف تعريف تطبيق الـ PWA لتثبيته كتطبيق مستقل على الهاتف والكمبيوتر.
- `sw.js` — Service Worker لتشغيل التطبيق بدون إنترنت (Offline) وتحديثه تلقائياً.
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — أيقونات التطبيق الرسمية.
- `.nojekyll` — لضمان نشر الملفات فوراً على GitHub Pages.

## 🌐 خطوات الرفع على GitHub Pages
1. أنشئ مستودعاً (Repository) جديداً على GitHub، وارفع داخله جميع الملفات الموجودة في هذه الحزمة.
2. ادخل إلى **Settings** > **Pages**.
3. تحت قسم **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. خلال ثوانٍ سيعمل الرابط الخاص بك، وعند فتحه سيظهر زر **📲 تثبيت التطبيق** لتثبيته على الشاشة الرئيسية.

## 🔄 كيف يعمل التطبيق والملف المخزن على الذاكرة كشيء واحد؟
1. **ربط مباشر بملف الذاكرة (`💾 ملف الذاكرة الموحد`)**: من الشريط العلوي، يمكنك الضغط على **💾 ملف الذاكرة الموحد** ثم **🔗 ربط مباشر بملف على الذاكرة** لاختيار ملف `binance_ledger_memory.json` على جهازك؛ أي تعديل في التطبيق يُكتب فوراً داخل الملف على الذاكرة، وأي تحديث في الملف يُقرأ تلقائياً عند فتح التطبيق.
2. **مزامنة سحابية ثنائية الاتجاه (GitHub Cloud / Google Drive)**: عند تفعيل الربط السحابي، يقوم التطبيق بسحب ورفع أحدث نسخة تلقائياً فور فتحه سواء فتحته من رابط GitHub Pages (PWA) أو فتحت ملف `index.html` المخزن على ذاكرة الهاتف.
